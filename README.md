# Alain Zaky — Personal Website

Personal portfolio for Alain Zaky, built as a lightweight static site for GitHub Pages.

## Local preview

Open `index.html` directly, or run a small local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publishing

GitHub Pages is configured to publish the `main` branch from the repository root.
